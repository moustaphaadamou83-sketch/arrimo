# OG · Copilote Arrimo

Identité intégrée uniquement dans la copie de préparation du 22 octobre 2026.

## Identité

Nom visible français : **OG · Copilote**. Anglais : **OG · Copilot**. Le titre comprend l'établissement courant. La marque Arrimo, sa palette et l'icône vectorielle existante du copilote sont conservées. Aucun acronyme d'OG, affiliation institutionnelle ou nouveau personnage n'est inventé.

Ton : clair, calme, opérationnel. Formulation d'accueil : « OG propose ; vous décidez. N'inscrivez aucune donnée personnelle ou médicale dans votre question. » L'avertissement équivalent existe en anglais.

## Contrat de comportement

Le briefing expose les faits calculés, la date et les raisons des recommandations. Les boutons passent par les autorisations et les API existantes. Une proposition de lit n'est pas une réservation ; l'action doit réussir pour être annoncée comme exécutée.

Les règles locales conservent les questions françaises et anglaises sur l'attente, le nettoyage, les civières et les prévisions. Aucun modèle clinique ni entraînement sur des données hospitalières réelles n'est revendiqué.

## IA externe facultative

Le mode reste désactivé dans le lanceur de présentation. Si une clé est explicitement configurée ailleurs dans cette copie : seules trois intentions prédéfinies en français et leurs équivalents anglais sont éligibles à un appel externe. Les questions libres restent locales. La requête utilise une liste de champs numériques et de niveaux autorisés : ni référence patient, ni nom d'établissement, ni lit, protocole ou texte libre. Les recommandations sont résumées par leurs nombres et priorités.

La requête possède un signal d'expiration de huit secondes. Une panne renvoie au mode local. Les tests utilisent un fournisseur simulé et vérifient l'absence d'une référence arbitraire, le refus d'une question libre et le repli. La qualité d'un fournisseur réel, son modèle configuré et ses conditions de traitement ne sont pas validés. Même agrégées, les données réelles nécessitent une décision explicite sur leur traitement.

## État de livraison

L'identité et les correctifs sont dans cette copie de travail, avec les traductions françaises et anglaises. Le service public garde sa version courante. Aucun renommage distant ni activation d'un fournisseur externe n'a été effectué.
